- **照片相册** — 保存原图，随时回看值得留下的画面。
- **代码收藏** — 归档源文件与小项目，让想法有迹可循。
- **小说书架** — 收好文字，继续还没写完的故事。

<sub>项目使用：TypeScript · React · Cloudflare Workers · D1 · R2</sub>
